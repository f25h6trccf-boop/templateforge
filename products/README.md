# TemplateForge product prototypes

These are functional **CSV spreadsheet prototypes**, not final retail-ready products. Open in Excel or import into Google Sheets. Edit the zero-value input cells. Calculated cells contain formulas. In the profit tracker, format the Profit Margin column as percentages.

The business profit tracker totals monthly revenue, expenses and net profit. The personal budget planner compares planned and actual amounts and calculates remaining cash flow.

**Do not sell or enable checkout yet.** Before launch, build polished XLSX editions, test formulas in Excel and Google Sheets, write usage instructions and licensing terms, and connect a payment processor with automated fulfillment. These prototypes are currently publicly accessible in this repository.
